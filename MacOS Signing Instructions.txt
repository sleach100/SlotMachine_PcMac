How to Code Sign SLOT Machine:

****************************************
SHORTCUT - USE SCRIPT:

CD Users/steveleach/SlotMachineDMG                                    
./codesign-slot-machine.sh   
****************************************


1) Open a new terminal and change the directory to /Users/steveleach/SlotMachineDMG/
2) copy /Users/steveleach/Documents/Projects/SlotMachine_PcMac/Builds.nosync/MacOSX/build/Release/SlotMachine.app to /Users/steveleach/SlotMachineDMG/ - Overwrite if already exists.
3) strip any attributes:  xattr -rc SlotMachine.app
4) Confirm no attributes left:  xattr -lr SlotMachine.app
5) Rename file:  mv SlotMachine.app "SLOT Machine.app"
6) Code sign the app:  

codesign --deep --force --options runtime \
--sign "Developer ID Application: Steven Leach (M5X8C8C6SW)" \
"SLOT Machine.app"

7) Zip up the app:  ditto -c -k --keepParent "SLOT Machine.app" "SLOT Machine.zip"
8) Submit zip file to apple:  

xcrun notarytool submit "SLOT Machine.zip" \
--keychain-profile "notary-profile" \
--wait

9) After Apple approves it, Staple:  xcrun stapler staple "SLOT Machine.app"
10) Verify:  spctl -a -t exec -vv "SLOT Machine.app"

11) Create DMG:

create-dmg \
--volname "SLOT Machine" \
--window-pos 200 120 \
--window-size 600 400 \
--icon-size 100 \
--icon "SLOT Machine.app" 150 200 \
--icon "Applications" 450 200 \
--background dmg-background.png \
--hide-extension "SLOT Machine.app" \
SlotMachine-1.0.0.dmg \
SlotMachineDMG/

12) Sign the DMG:  codesign --force --sign "Developer ID Application: Steven Leach (M5X8C8C6SW)" "SlotMachine-1.0.0.dmg"

13) Verify:  codesign --verify --verbose=2 "SlotMachine-1.0.0.dmg"
