Windows 11 Install Steps

You’ll likely see SmartScreen once, then a standard “User Account Control” prompt.

1
Click “Download Windows Trial”
Save the installer, then open it from your browser’s downloads list.
2
On “Windows protected your PC”, click “More info”
This is the SmartScreen warning. It’s Windows being cautious with new apps.
SmartScreen warning — click More info.
3
Click “Run anyway”
After “More info”, Windows shows the app name and publisher, and reveals the Run anyway button.
SmartScreen details — click Run anyway.
4
Approve the Windows “User Account Control” prompt
This is the standard “Allow this app to make changes to your device?” prompt. Click Yes to continue.
Windows UAC prompt — click Yes.
5
Finish the Setup Wizard
Click Next to install. When it finishes, launch S.L.O.T. Machine and start building grooves.
Setup Wizard — click Next to continue.
